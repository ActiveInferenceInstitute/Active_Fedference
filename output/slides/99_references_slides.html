References

The bibliography lives in project bibliography source and is read by Pandoc during rendering. The combined PDF path invokes --natbib, so citation markers become LaTeX citation commands resolved against the bib file. HTML, reveal.js, and other non-LaTeX reader surfaces use --citeproc against that same file.
